# 캐릭터·규칙 설계 정리

> 함께 정리하는 문서. **확정**은 구현 기준, **미정**은 논의할 것.
> 확정된 항목 중 아직 코드에 반영하지 않은 것은 `⏳ 미반영`으로 표시.

## 1. 용어

| 용어 | 뜻 |
|---|---|
| 열 | 세로줄. 내 위치에서 상대 진영 쪽으로 뻗는 방향 |
| 행 | 가로줄. 같은 진영 안에서 옆으로 |
| 칸 조준 | 칸을 정해서 쏨. 이동이 먼저 처리되므로 상대가 움직이면 빗나감 |
| 유닛 지정 | 특정 유닛을 지정해 무조건 맞힘 (유도탄 마법사만 해당) |
| 스킬 | 공격·치유·마법처럼 이동이 아닌 행동 |

## 2. 확정된 규칙

### 판
- 6×6, 각 진영 3줄(18칸), 중립 줄 없음. 상대 진영에는 들어갈 수 없음
- 위험지대: 5턴부터 뒷줄, 3턴마다 한 줄씩 넓어짐(최대 2줄), 턴 끝 최대 체력 25% 피해. 앞줄은 항상 안전

### 턴
- 매 턴 행동 3개를 미리 입력하고 동시에 처리
- ⏳ 미반영 **행동 3개 중 이동 최소 1회** (기존 "공격 최대 2회" 규칙을 대체)

### 캐릭터 공통
- 모든 캐릭터는 원거리. **조준 범위가 좁을수록 강함**
- 공격은 항상 **칸 조준** (예외: 유도탄 마법사)
- ⏳ 미반영 열 공격은 **첫 유닛에 막힘** (지금 코드는 관통 50% 감쇠가 기본값. 기본값을 0으로 변경 예정)
- 관통은 나중에 얻는 능력 (방식 미정)

### 치유
- 치유는 행동 1개를 소비하므로 **별도 회복 상한 없음**
- 단, **치유 1회 회복량 < 같은 범위 포수의 공격 1회 피해** (반대가 되면 아무도 죽지 않음)
- 기존 "턴당 최대 체력 10%" 상한은 행동 없이 회복되는 특수능력(자체 회복·흡혈)에만 적용

### 무효(마법사a)
- 칸에 맞은 유닛의 **다음 행동 1회가 무효**
  - 같은 턴 뒤 스텝에 그 유닛의 행동이 남아 있으면 → 그 행동이 무효
  - 남은 행동이 없으면 → 다음 턴 첫 행동이 무효 (상태가 화면에 공개됨)
- 같은 스텝에 동시에 일어난 행동은 무효가 되지 않음 (동시 사망과 같은 원칙)

## 3. 캐릭터 초안

세기는 상대 비교: 강 > 중 > 약. 수치는 시뮬레이션으로 결정.

### 포수 (피해)
| 이름 | 조준 범위 | 공격력 | 비고 |
|---|---|---|---|
| 포수a | 같은 열만 | 강 | 첫 유닛에 막힘 |
| 포수b | 다른 열만 (내 열 제외) | 중 | |
| 포수c | 아무 칸 | 약 | |

### 힐러 (치유, 공격력 모두 약)
| 이름 | 치유 범위 | 치유량 | 비고 |
|---|---|---|---|
| 힐러a | 같은 행 아군 전체 | 많음 | |
| 힐러b | 같은 열 아군 | 체력 가득 | 미정 (아래 Q3) |
| 힐러c | 아무 칸, 아군 1명 | 보통 | |
| 힐러d | 아무 칸, 범위 2×2 또는 3×3 | 적음 | 범위 크기 미정 |

### 마법사
| 이름 | 조준 범위 | 효과 | 공격력 |
|---|---|---|---|
| 마법사a | 같은 열 | 무효 | 중 (피해도 같이 주는지 미정, Q2) |
| 마법사b | (작성 예정) | | |
| 유도탄 마법사 | 상대 유닛 지정, 무조건 명중 | 피해 | 가장 약함 |

## 4. 미정 — 같이 정할 것

| # | 질문 | 추천 |
|---|---|---|
| Q1 | "이동 최소 1회"의 예외: 움직일 칸이 하나도 없을 때(아군에 막힘 등)는? 대기로 대신할 수 있나? | 이동할 수 있는 칸이 없으면 면제. 대기는 이동으로 치지 않음 |
| Q2 | 마법사a는 무효와 피해를 같이 주나? | 피해를 같이 주면 피해를 약하게. 아니면 무효만 주고 조준 범위를 넓게 |
| Q3 | 힐러b "체력 가득"은 너무 강하지 않나? | 쓴 뒤 몇 턴 동안 다시 못 쓰는 재사용 대기시간, 또는 치유 대상 1명으로 제한 |
| Q4 | 관통 능력을 얻는 방식 | 특수능력 슬롯 중 하나로 (가챠·리롤로 획득) |
| Q5 | 힐러가 자기 자신도 치유하나? 같은 행·열 범위에 자신 포함? | 포함 (아니면 힐러끼리만 서로 살리는 구조가 됨) |
| Q6 | 포수b "다른 열만"은 직선인가, 다른 열의 아무 칸인가? | 다른 열의 아무 칸 (칸 조준) |
| Q7 | 기존 챔프 7종(돌격병·저격수 등)은 새 체계로 전부 교체하나? | 교체. 이름만 재활용할지는 선택 |

## 5. 다음 구현 순서 (목록이 정리되면)

1. 엔진을 "조준 방식 × 효과(피해·치유·무효) × 세기" 데이터 구조로 개편
2. 위 ⏳ 미반영 규칙 반영 (이동 최소 1회, 막힘 기본값)
3. 캐릭터 데이터 입력 → 시뮬레이션으로 세기 수치 결정 (기준: 공격력 × 맞힐 수 있는 칸 수 ≈ 일정)
4. AI가 치유·무효를 판단하도록 확장
