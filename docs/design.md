# 캐릭터·규칙 설계 정리

> 함께 정리하는 문서. **확정**은 구현 기준, **미정**은 논의할 것.
> 확정된 항목 중 아직 코드에 반영하지 않은 것은 `⏳ 미반영`으로 표시.

## 1. 용어

**턴·행동·이동·액션·대기 (2026-11-24 확정)** — 대화·화면·문서 모두 이 용어만 쓴다

| 용어 | 뜻 | 예시 |
|---|---|---|
| **턴** | 양쪽이 동시에 입력하고 함께 처리되는 한 번 | 1턴 … 최대 20턴 |
| **행동** | 한 턴에 입력하는 3번의 순서. 행동 1 → 2 → 3 순으로 처리. 행동 하나 = 이동 / 액션 / 대기 중 하나 | "행동 1로 이동, 행동 2로 공격" |
| **이동** | 행동의 한 종류. 칸 옮기기 | a5 → a4 |
| **액션** | 행동의 한 종류. **이동이 아닌 것 전부** (공격·회복·버프·무효 등) | 새 특수능력도 이동이 아니면 자동으로 액션 |
| **대기** | 행동의 한 종류. 아무것도 안 함 (액션 아님) | 행동 1을 비워 두기 |

그 밖의 용어

| 용어 | 뜻 |
|---|---|
| 열 | 세로줄. 내 위치에서 상대 진영 쪽으로 뻗는 방향 |
| 행 | 가로줄. 같은 진영 안에서 옆으로 |
| 칸 조준 | 칸을 정해서 쏨. 이동이 먼저 처리되므로 상대가 움직이면 빗나감 |
| 유닛 지정 | 특정 유닛을 지정해 무조건 맞힘 (특수능력 "유도"만 해당) |
| 거리 | 맨해튼 거리 = 가로 칸 수 + 세로 칸 수 (a1 → f6 = 10) |
| 개체 | 뽑기로 얻은 유닛 하나. 그림·능력치·특수능력을 가짐 |

## 2. 밸런스 목표

- 캐릭빨은 있지만 **실력·논리로 어느 정도 뒤집을 수 있어야** 함 (뽑기 결과가 전부인 구조는 피함)
- **실력이 같으면 캐릭터가 좋은 쪽이 약 67% 승리 (2승 1패)**. 시뮬레이션으로 능력치 폭을 이 목표에 맞춘다
- 원칙: 실제 화력 = 공격력(캐릭빨) × 명중률(실력) → 뽑기로 생기는 숫자 차이는 좁게, 선택지(능력)는 넓게
- 판 안에는 운이 없다 (확률 회피·확률 방어 없음). 맞히느냐는 순전히 읽기 실력

## 3. 확정된 규칙

### 판
- 6×6, 각 진영 3줄(18칸), 중립 줄 없음. 상대 진영에는 들어갈 수 없음
- 출전 **4개** (5개·4×4 검토 후 결정. 5개는 시뮬레이션 후 재검토 가능)
- **위험지대: 오리지날 맵에는 없음** (2026-11-24 확정). 이벤트 맵용으로 설정만 남겨 둠 — 켜면 5턴부터 뒷줄, 3턴마다 한 줄씩 넓어짐(최대 2줄), 턴 끝 최대 체력 25% 피해

### 턴
- 매 턴 행동 3번을 미리 입력하고 동시에 처리. 행동 1 → 2 → 3 순서로, 같은 번호의 행동끼리 양쪽 동시에 처리
- **이동 의무 없음** (2026-11-24 확정): 행동은 전부 대기여도 됨. 제한시간 안에 아무것도 안 넣으면 대기 3번
- **액션은 턴당 최대 2번, 캐릭당 최대 1번** (몇 명 남았든 같음)
- **같은 캐릭이 여러 행동 가능** (예: 이동 → 이동 → 액션, 액션 → 이동). 행동은 대기로 비워도 됨
- 행동 입력은 앞 행동을 반영한 위치 기준 (행동 1로 옮겼으면 행동 2의 사거리는 옮긴 자리에서)
- 같은 번호의 행동 안에서는 이동이 액션보다 먼저 처리됨 → 상대가 움직일 행동 번호를 읽는 것이 심리전의 핵심

### 이동
- 이동력 N = **1칸 이동을 N번**. 1칸 이동은 상하좌우 4방향 중 하나
- 이동력 이하로 자유롭게 (이동력 2여도 1칸만 가도 됨). 제자리로 돌아오는 이동은 불가
- 칸마다 방향을 바꿀 수 있음 → 이동력 2면 대각선·ㄱ자 위치에도 도착 가능
  - 예: a1(나), a2·b3 아군 → 오른쪽 1칸(a2 건너 a3) → 아래 1칸(b3 건너 c3) → c3 도착
- **아군은 건너뜀**: 이동력은 빈칸만 센다
  - 예: a1 → 오른쪽 1칸, a2에 아군 → a3 도착 (a2는 그대로)
  - 예: a1 → 오른쪽 1칸, a2·a3에 아군 → a4 도착
  - 예: 이동력 2, a2 아군·a3·a4 빈칸 → a4 도착
- 그 방향으로 내 진영 끝까지 필요한 빈칸이 없으면 **그 방향으로는 이동 불가**
- 내 진영 밖으로는 못 나감 → 앞줄에서 더 앞으로는 이동 불가
- 이동끼리 충돌하는 경우가 없음 (이동 경로엔 아군만, 같은 번호의 행동은 진영당 1개)
- **도착 칸은 입력한 칸으로 고정**: 앞 행동에서 건너뛰려던 아군이 죽어도 처음 입력한 칸에 도착

### 공격
- 모든 공격은 **칸 조준**, 사거리 안의 상대 칸 1칸 (예외: 특수능력 "유도")
- 중간에 막히지 않음 (가로줄·열 같은 조준 모양 없음 → 기존 "열 공격은 첫 유닛에 막힘" 규칙 폐기)
- 받는 피해 = 공격력 − 방어력 (예: 20 − 5 = 15)

### 캐릭터 = 그림 8종
- 그림은 **성능과 무관**. 능력치·특수능력은 개체마다 뽑기로 정해짐
- 그림은 개체에 고정 (바꿀 수 없음)
- **같은 그림은 한 팀에 중복 출전 불가** (상대와는 같아도 됨)
- 의도: 좋은 개체가 원하는 그림에 안 붙는 아쉬움 → 뽑기 동기
- 역할 구분(포수·힐러·마법사) 없음. 예전 역할 초안의 능력은 전부 특수능력으로 옮김

### 능력치
| 능력치 | 범위 | 비고 |
|---|---|---|
| 공격력 | 15~20 | |
| 방어력 | 1~5 | 최소 피해 15 − 5 = 10 → 피해가 공격력의 2/3 밑으로 안 떨어짐. 추가 규칙 없음 |
| 체력 | 30~50 | 최대 피해 19 < 최소 체력 30 → 한 방에 죽는 일 없음 |
| 이동력 | 1~2 | 뽑기인지 고정인지 미정 (Q9) |
| 사거리 | 5~10 | 뽑기인지 고정인지 미정 (Q9) |
- 민첩(확률 회피) 없음. 피하기 = 이동
- 우려: 범위 그대로 랜덤이면 최고 개체 vs 평범한 개체 승률이 67%를 넘을 가능성 높음 → Q10

### 특수능력 (뽑기)
- 개체당 **0개 또는 1개**
- **붙을 확률 20% / 안 붙을 확률 80%**. 붙을 때는 모든 종류가 **균등 확률**
- 확률이 균등하므로 **종류끼리 세기를 비슷하게** 맞춘다 (꽝 능력이 없게)
- 목록은 4장 초안

### 치유 (공통 규칙)
- **회복량 = 치유 대상의 공격력 × 치유 비율** (예: 대상 공격력 15, 비율 60% → 9)
- 치유하는 쪽의 능력치는 회복량에 영향 없음
- 치유는 액션이므로 별도 상한 없음. 단 **치유 1회 회복량 < 공격 1회 피해**가 되게 비율을 잡는다
- 액션 없이 회복되는 능력(이동 시 자가 회복·흡혈)은 둘 다 턴당 1번. **턴당 상한(최대 체력 10%)은 2026-11-24 없앰** (설정 passiveHealCapBp 로 되살릴 수 있음)

### 무효 (공통 규칙)
- 맞은 유닛의 **다음 행동 1회가 무효**
  - 같은 턴 뒤쪽 행동에 그 유닛의 행동이 남아 있으면 → 그 행동이 무효
  - 남은 행동이 없으면 → 다음 턴 첫 행동이 무효 (상태가 화면에 공개됨)
- 같은 번호의 행동에서 동시에 일어난 행동은 무효가 되지 않음 (동시 사망과 같은 원칙)

## 4. 특수능력 초안

> 대충 적은 후보 목록. 수치는 전부 초안이고 시뮬레이션으로 정한다.
> 처음엔 이 중 6~8종을 골라 시작하는 것을 추천 (종류가 많을수록 원하는 능력이 나올 확률이 낮아짐).

**대가 원칙**: 공격에 효과가 실리는 능력은 그만큼 피해가 줄어야 공평하다. 공격 대신 쓰는 능력은 "그 액션으로 공격을 못 함"이 대가.

### 공격 대신 쓰는 능력 (액션형)
| 능력 | 효과 | 초안 수치 | 비고 |
|---|---|---|---|
| 치유 | 사거리 안 아군 1명 회복 | 대상 공격력의 60% | 자기 자신 포함 여부 Q5 |

### 공격에 실리는 능력
| 능력 | 효과 | 초안 수치 | 비고 |
|---|---|---|---|
| 무효 | 맞은 유닛의 다음 행동 1회 무효 | 피해 50% | 예전 "마법사a" |
| 속박 | 맞은 유닛의 다음 이동 1회 무효 | 피해 70% | 피하기를 막음. 무효보다 약하니 피해 감소도 적게 |
| 관통 | 상대 방어력 무시 | 피해 100% | 칸 조준이 막히지 않으므로 "뒤까지 뚫기" 대신 방어력 무시로 재해석 |
| 폭발 | 맞은 칸 + 상하좌우 4칸에 피해 | 중심 70%, 주변 40% | 빗나가도 옆에 걸릴 수 있음 |
| 유도 | 칸 대신 상대 유닛 지정, 무조건 명중 | 피해 40% | 읽기 싸움을 건너뛰므로 가장 약하게 |

### 저절로 발동하는 능력 (패시브)
| 능력 | 효과 | 초안 수치 | 비고 |
|---|---|---|---|
| 보호막 | 매치 시작 시 보호막 (피해를 먼저 흡수, 다시 안 참) | 15 | 기존 능력, 수치 재조정 |
| 반사 | 받은 피해 일부를 공격자에게 | 25% | 기존 능력 |
| 흡혈 | 준 피해 일부만큼 회복 | 30% | 기존 능력. 턴당 상한 적용 |
| 자체 회복 | 턴 끝 회복 | 3 | 기존 능력. 턴당 상한 적용 |

## 6. v2 구현 상태 (`packages/v2`, 2026-11-23)

기존 엔진·화면은 그대로 두고 새 규칙을 별도 패키지로 구현. 시뮬레이션: `SIM=1 npx vitest run packages/v2/test/sim.test.ts`

- 구현: 아군 건너뛰기 이동·도착 칸 고정·칸 조준 + 사거리, 그림 중복 금지, 능력치 뽑기, 특수능력 20%·균등, docs/spec 특수능력 18종 중 17종
- **제외: 7. 투명 이동** — 상대 화면에서 위치를 숨기는 장치가 필요하고, 규칙 미정 (숨은 칸을 그냥 쏴서 맞힐 수 있나 / 광역딜·유도탄에 맞나 / 내 회복으로도 풀리나)
- 기능 해석으로 임시로 정한 것 (수치 아님):
  - 특수능력이 있어도 일반 공격 가능. 액션형 능력(회복·버프)은 액션 1번을 씀
  - 회복: 사거리 안 아군, 자기 자신 포함. 광역 회복·광역딜은 칸을 조준해 3×3
  - 유도탄: 유닛 지정(입력 때 사거리 안), 무조건 명중. 이 유닛의 공격은 항상 유도탄
  - % 피해: 방어력을 먼저 빼고 % 적용, 최소 1. 퍼센트딜은 대상 최대 체력 기준으로 더함. 방어력 무시 50% = 방어력 절반(내림) 무시
  - 무효: 피해는 그대로 + 맞은 유닛의 다음 행동 1회 취소 (행동할 때까지 유지)
  - 이동수 제어: 다음 턴 이동력 −1, 중첩 없음
  - 맹독: 공격자 공격력 기준, 맞은 턴 포함 2턴 턴 끝 피해, 방어력 무시, 중첩 제한 없음
  - 반사: 받은 피해 기준, 재반사 없음
  - 흡혈·이동 시 자가 회복: 턴당 1번, 상한 없음 (2026-11-24 상한 삭제)
  - 버프: 사용한 턴 포함 2턴, 사용한 턴부터 3턴 뒤 재사용, 즉시 적용. 이동수 증가·모두 레벨업은 자신만
  - 같은 행동 안 처리 순서: 이동 → 버프 → 공격. 회복을 먼저 반영하고 피해는 동시
  - 이동력·사거리도 개체마다 뽑기 (범위 안 균등)
  - 기존 규칙 유지: 20턴 판정, 10턴부터 회복 50%, (행동 규칙은 아래 "행동 규칙 결정" 참고)

### 시뮬레이션에서 나온 핵심 발견
- 이동을 1번째 행동에 하는 AI가 크게 이김 (1번째 76% vs 마지막 25%)
  - 규칙 문제가 아니라 **AI가 너무 뻔해서** 생긴 결과로 판단 (2026-11-23 논의): 한 행동에 움직일 수 있는 건 1명뿐이라 나머지 3명은 제자리 → "누가 움직일지" 읽고 남는 유닛을 찍는 게 전략. 지금 AI는 양쪽 다 "가장 위협받는 유닛"만 움직이고 그 유닛만 노려서 늘 빗나감
  - 장기에서 어느 쫄을 먼저 여는지처럼 순서 선택 자체가 전략. 일찍 공격 = 제자리 유닛을 확실히 맞힘 / 일찍 이동 = 그 유닛만 피함
- 양쪽이 다 먼저 움직이면 대부분 빗나가서 판이 길어짐 (평균 16.5턴, 44%가 20턴 판정) → 같은 AI 문제일 가능성 높음
- 현재 AI는 단순해서 특수능력·능력치 세부 수치 비교는 아직 믿기 어려움 (능력치가 높은데 지는 결과가 나옴)

### 혼합 전략 AI 도입 후 (2026-11-23)
- AI: 매 턴 양쪽 후보 계획 최대 14개 × 14개를 엔진으로 처리 → regret matching 으로 섞는 비율 → 그 비율로 선택. 꼼수 AI 4종에 90~100% 승
- **잘 읽는 사람끼리면 판이 안 끝남: 86%가 20턴 판정 (평균 19.6턴)** → 판을 끝내는 규칙 보강 필요 (위험지대 강화·피해 증가·행동 수·서든데스 중 선택)
- 실제 뽑기 분포: 능력치 상위 10% vs 중간 59%, 상위 vs 하위 68% (목표 67%에 근접. 단 판정 영향 큼)
- 특수능력(최고 등급, 각 60판): 회복 계열·방어력 무시·도핑 64~68%, 나머지 대부분 47~58%. 판정승 구조라 버티는 능력이 유리하게 나옴

### 행동 규칙 결정 (2026-11-24) — 규칙 ② 채택
- **한 턴 행동 3번. 같은 캐릭이 여러 행동 가능** (예: 이동 → 이동 → 액션, 액션 → 이동)
- **액션(공격·마법·회복·버프 등 이동이 아닌 것)은 턴당 최대 2번, 캐릭당 1번** (남은 수와 무관, 1명 남아도 1번)
- 행동은 대기로 비워도 됨. 예: 행동 1 대기 → 행동 2부터. 이동 의무 없음 (아무것도 안 하면 대기 3번)
- 규칙에 안 맞는 계획(조작된 입력 등)은 그 턴 전부 대기로 처리
- 참고: 위 비교 시뮬레이션은 이동 최소 1번 규칙이 있을 때 결과
- 행동 입력은 앞 행동을 반영한 위치 기준 (행동 1로 옮겼으면 행동 2의 사거리는 옮긴 자리에서)

비교 (혼합 AI, 위험지대 켬, 판 60~100번):

| 항목 | ① 캐릭당 1번 (2명 2·1명 3) | **② 행동 자유·액션 캐릭당 1** | ③ ② + 1명이면 액션 2 |
|---|---|---|---|
| 평균 판 길이 | 19.4턴 | 18.4턴 | 19.4턴 |
| 전멸로 끝남 | 12% | 24% | 14% |
| 평균 덱 vs 최악 덱 | 30% | 90% | 15% |
| 뽑기 상위 10% vs 중간 | 60% | 63% | 52% |
| 몰빵 덱(최강1+최약3) vs 평균 | 71% | 72% | 73% |

- ①에서 최악 덱이 이기던 원인은 위험지대 (끄면 30% → 69%). ②는 "나가서 쏘기"가 되므로 위험지대가 있어도 정상
- ③의 역전 현상은 원인 미확인 (AI가 1명 남았을 때 피하지 않는 것으로 추정)
- 남은 과제: 몰빵 덱 72% (강한 1명의 영향이 큼), 만점 덱 vs 평균 99%
- 시뮬레이션: `SIM=1 npx vitest run packages/v2/test/rs-`

### 진영 차이 확인 (2026-11-24)
- 같은 덱 쌍을 진영만 바꿔 2판씩 비교 (`SIM=1 npx vitest run packages/v2/test/rs-side`)
- AI 수정 전 (덱 100쌍): 오리지날 A 41% / B 59% → 원인은 엔진이 아니라 AI (방향 고르는 순서가 진영마다 달랐음)
- 수정: AI 는 항상 판을 "내가 A(아래)" 로 뒤집어 생각하고 결과만 되돌림 → 구조적으로 대칭. 엔진 대칭은 `test/symmetry.test.ts` 로 확인 (뒤집은 판 처리 = 처리 결과 뒤집기)
- AI 수정 후 (덱 300쌍 = 600판): **오리지날 A 49% / B 51%**, 위험지대(이벤트) A 48% / B 52% → 진영 차이 없음 (오차 ±4%p 안)
- 참고: 무작위 덱끼리는 "같은 덱이 2판 다 이김" 152쌍 vs "같은 진영이 2판 다 이김" 147쌍 → 비슷한 덱끼리는 덱보다 수 싸움이 승패를 가름

### 1대1 종료 (2026-11-24 확정)
- 양쪽 다 1명씩 남으면 그 자리에서 판정 (처음부터 1대1인 판은 해당 없음)
  1. **남은 체력** 많은 쪽 승 (그 캐릭의 남은 체력 그대로)
  2. 같으면 **능력치 점수 낮은 쪽 승** = 공격력 + 방어력 + 체력 + 이동 + 사거리 (뽑을 때의 원래 수치, 체력은 최대 체력, 버프·약화 무시) + 특수능력 있으면 +20
  3. 그것도 같으면 판정 없이 1대1 계속 → 달라지는 순간 다시 판정. 20턴까지 같으면 무승부
- 20턴 판정은 그대로 (팀 남은 체력 비율)
