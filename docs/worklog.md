# 작업 기록 (요청 · 결정 · 진행 상황)

> 여러 컴퓨터에서 이어서 작업하기 위한 기록. **새로 작업을 시작하면 이 파일부터 읽고, 요청을 받을 때마다 맨 아래에 추가한다.**
> 규칙의 최종 기준은 [design.md](design.md), 특수능력 원문은 [spec](spec). 이 파일은 "누가 언제 무엇을 요청했고 어떻게 됐는지"의 기록.
> 형식: 날짜 · 요청(사용자 말 요약) → 결과 / 결정 / 남은 일. 커밋 해시가 있으면 함께.

## 소통 규칙
- 사용자에게 보이는 글은 **항상 한국어** (코드·명령·경로만 영어)
- 용어: 턴 · 행동(한 턴 3번) · 이동 · 액션(이동 외 전부) · 대기 — design.md 1장
- 밸런스 목표: 캐릭빨은 있되 실력으로 뒤집을 여지. 실력이 같으면 좋은 쪽이 약 67% (2승 1패). 과금빨(모두의마블식) 싫음
- 서버(Supabase "multi" 프로젝트) 비밀 키는 앱·대화·커밋에 절대 넣지 않음. `supabase config push` 는 사용자 동의 없이 금지
- 커밋·푸시는 사용자가 요청할 때만
